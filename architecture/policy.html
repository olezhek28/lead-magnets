Политика конфиденциальности

1. Общие положения

Политика обработки персональных данных составлена согласно Федеральному закону от 27.07.2006 № 152-ФЗ «О персональных данных». Оператор — Козырев Олег Вячеславович — обязуется соблюдать права человека при обработке данных и защищать приватность. Политика применяется ко всей информации о посетителях веб-сайта https://guide.olezhek28.courses/.

2. Основные понятия

  • Автоматизированная обработка персональных данных — обработка с использованием вычислительной техники
  • Блокирование — временное прекращение обработки
  • Веб-сайт — совокупность материалов и программ по адресу https://guide.olezhek28.courses/
  • Обезличивание — действия, исключающие определение принадлежности данных конкретному лицу
  • Обработка персональных данных — любые операции с данными: сбор, запись, хранение, удаление, уничтожение
  • Оператор — физическое лицо, организующее обработку данных
  • Персональные данные — информация о конкретном пользователе
  • Пользователь — любой посетитель сайта
  • Трансграничная передача — передача данных иностранным государствам
  • Уничтожение — безвозвратное удаление данных

3. Права и обязанности Оператора

Права:

  • Получать достоверную информацию от субъектов персональных данных
  • Продолжить обработку после отзыва согласия при наличии оснований в законе
  • Самостоятельно определять меры для обеспечения безопасности

Обязанности:

  • Предоставлять информацию об обработке по запросу
  • Организовывать обработку по законодательству РФ
  • Отвечать на запросы субъектов данных
  • Сообщать в уполномоченный орган необходимую информацию
  • Публиковать политику в открытом доступе
  • Принимать правовые, организационные и технические меры защиты
  • Прекращать передачу и уничтожать данные при необходимости

4. Права и обязанности субъектов персональных данных

Права:

  • Получать информацию об обработке собственных данных
  • Требовать уточнения, блокирования или уничтожения неполных или неточных данных
  • Выдвигать условие предварительного согласия на маркетинговую обработку
  • Отозвать согласие на обработку
  • Обжаловать неправомерные действия в уполномоченный орган или суд

Обязанности:

  • Предоставлять достоверные сведения о себе
  • Сообщать об уточнениях и изменениях персональных данных

Лица, передавшие недостоверные сведения или информацию о других лицах без согласия, несут ответственность.

5. Принципы обработки

  • Обработка осуществляется на законной и справедливой основе
  • Ограничивается достижением конкретных, заранее определённых целей
  • Объединение баз данных с несовместимыми целями недопустимо
  • Обрабатываются только данные, соответствующие целям
  • Объём данных не должен быть избыточным
  • Обеспечивается точность и актуальность информации
  • Хранение осуществляется не дольше необходимого срока

6. Цели обработки персональных данных

  • Цель: информирование пользователя посредством электронных писем
  • Данные: фамилия, имя, отчество, электронный адрес, ник Telegram
  • Основание: Федеральный закон «Об информации, информационных технологиях и о защите информации» от 27.07.2006 N 149-ФЗ
  • Виды обработки: сбор, запись, систематизация, накопление, хранение, уничтожение, обезличивание, отправка писем

7. Условия обработки персональных данных

Обработка осуществляется:

  • С согласия субъекта персональных данных
  • Для достижения целей международных договоров или законодательства
  • Для исполнения судебных актов
  • Для исполнения договоров
  • Для осуществления прав и интересов оператора
  • Обработка общедоступных данных
  • Обработка данных, подлежащих опубликованию по закону

8. Порядок сбора, хранения, передачи и обработки

  • Оператор обеспечивает сохранность данных и исключает доступ неуполномоченных лиц
  • Персональные данные не передаются третьим лицам, кроме случаев исполнения законодательства или с согласия субъекта
  • Пользователь может актуализировать данные, отправив уведомление на olezhek28.courses@gmail.com с пометкой «Актуализация персональных данных»
  • Срок обработки определяется достижением целей сбора
  • Пользователь может отозвать согласие, направив уведомление на olezhek28.courses@gmail.com с пометкой «Отзыв согласия на обработку персональных данных»
  • Информация сторонних сервисов, платёжных систем обрабатывается в соответствии с их политикой; оператор не несёт за них ответственность
  • Установленные запреты на передачу не действуют в государственных и публичных интересах
  • Оператор обеспечивает конфиденциальность данных
  • Хранение осуществляется не дольше необходимого срока
  • Прекращение обработки происходит при достижении целей, истечении согласия или его отзыве

9. Перечень действий Оператора с персональными данными

Сбор, запись, систематизация, накопление, хранение, уточнение, извлечение, использование, передача, обезличивание, блокирование, удаление, уничтожение. Автоматизированная обработка с передачей по информационным сетям.

10. Трансграничная передача персональных данных

До начала трансграничной передачи оператор уведомляет уполномоченный орган о намерении. Оператор предварительно получает сведения от иностранных органов власти и лиц.

11. Конфиденциальность персональных данных

Оператор и лица, получившие доступ к данным, обязаны не раскрывать и не распространять персональные данные без согласия субъекта, кроме случаев, предусмотренных федеральным законом.

12. Заключительные положения

  • Пользователь может получить разъяснения по вопросам обработки данных, обратившись на olezhek28.courses@gmail.com
  • Любые изменения политики будут отражены в документе
  • Политика действует бессрочно до замены новой версией
  • Актуальная версия расположена по адресу https://guide.olezhek28.courses/architecture/policy.html
