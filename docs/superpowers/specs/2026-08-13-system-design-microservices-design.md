# Закрытая копия System Design для выпускников микросервисов

Дата: 13 августа 2026

## Зачем

Тем, кто уже прошёл у нас курс по микросервисам, отправляем в личку персональную
ссылку на System Design. Они платят по полной цене, а скидку получают промокодом
на шаге оплаты в GetCourse — на странице промокод не упоминается вообще.

Существующая копия `system_design_booking/` под это не подходит: она вся построена
на предзаписи («цена предзаписи, действует до 23 августа», «самая низкая цена»),
а тут продажи уже открыты и дедлайна по дате нет.

## Что создаём

`system_design_microservices/` — полная копия `system_design_booking/` со всеми
картинками, видео и юридическими страницами (`policy.html`, `agree.html`,
`marketing-agree.html`, `doc.css`, `favicon.svg`, `og-image.*`).

Адрес: `guide.olezhek28.courses/system_design_microservices/`

Страница закрыта от индексации так же, как booking-копия: `noindex, nofollow` плюс
`yandex: none`. В `sitemap.xml`, `llms.txt`, `llms-full.txt`, `robots.txt` и в каталог
на главной её НЕ добавляем — ссылку рассылаем руками. В выдаче должна оставаться
только основная `/system_design/`, иначе три копии одного курса начнут
конкурировать друг с другом.

Перебиваем на новую папку: `canonical`, `og:url`, `og:image`, `twitter:image`,
все `@id` и `url` в JSON-LD.

в CSS про достоверность базовой цены (п. 4.1 ст. 16.1 ЗоЗПП) переписываем, чтобы
он не противоречил разметке.

## Формы оплаты

Свои формы GetCourse, отличные от booking-копии. `uniq` — это значение атрибута
`id` у выданного GetCourse тега `<script>`; им форма подписывает postMessage со
своей высотой, менять нельзя.

```js
var FORMS = {
  standart: { id: '1639196', uniq: '0d1ef533cb8f5444a3d95cf416a69ca1c11dfdb8', title: 'Оплата курса, тариф «Стандарт»' },
  mentor:   { id: '1639245', uniq: '647b02a9302c5c8cc450b899d13d78f9f95fb851', title: 'Оплата курса, тариф «С проверкой и практикой»' }
};
```

`href`-фолбэки на кнопках тарифов: `/pl/lite/widget/widget?id=1639196` и `?id=1639245`.

В GetCourse эти формы называются «SysDes 1.0 | Стандарт» и «SysDes 1.0 | С проверкой»,
то есть они не привязаны к выпускникам микросервисов — разделение только по промокоду.

## Метрика

Счётчик тот же, 96022201 (общий для домена, подключается через `/consent.js`).
Цели переименовываем `sdb_*` → `sdm_*`: `sdm_cta_click`, `sdm_form_open`. Так
конверсия этой аудитории считается отдельно от booking-копии.

## Синхронизация

Даты, цены и состав курса унаследованы от основной страницы. Теперь копий три:
`system_design/`, `system_design_booking/`, `system_design_microservices/`. При смене
потока править надо все, расхождение первыми увидят те, кому ссылку прислали лично.
