Цель обработки персональных данных: рассмотрение заявок и запросов пользователей Сайта; установление и поддержание связи с потенциальными клиентами; направление потенциальным клиентам сообщений информационного (нерекламного) характера, уведомлений, запросов, ответов, документов, касающихся порядка оказания услуг.

Для достижения указанной цели я разрешаю обработку следующих данных:

  • иные сведения, представленные субъектом персональных данных и отвечающие указанной цели обработки персональных данных.

Обработка персональных данных включает: сбор, запись, систематизацию, накопление, хранение, уточнение (обновление, изменение), извлечение, использование, передачу (предоставление, доступ), блокирование, удаление, уничтожение персональных данных.

Обработка осуществляется с применением следующих основных способов: автоматизированная обработка персональных данных с передачей полученной информации по информационно-телекоммуникационным сетям или без таковой; обработка без использования средств автоматизации; смешанная обработка персональных данных.
